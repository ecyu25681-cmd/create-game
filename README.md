# 勇者のあとしまつ

勇者が帰った、そのあとに。掃除で集めた資材とお金でダンジョンを改装し、7日間の営業で評判を育てるブラウザゲームです。

## 遊ぶ

`dist/index.html` をブラウザで開くと遊べます。Node.js があれば `npm start` で http://127.0.0.1:4318 に起動できます。追加パッケージは不要です。

1. ほうきで落とし物を拾い、お金と資材を回収。
2. 点線の通路に罠・宝箱・ベンチを配置。
3. 夜の営業を開始し、冒険者の反応と評価を観察。
4. 利益と設備を翌日に引き継ぎ、7日目に伝説の勇者を迎えます。

クリック・タッチで操作。1〜7で道具切替、ゲーム画面にフォーカスして矢印＋Enterでマス操作、Ctrl/⌘＋Zで取り消し。夜はSpaceで一時停止、ボタンで1/2/4倍速。準備に時間制限はありません。

粘液から3マス以内の次のトゲは連携ダメージ。冒険者が途中帰宅しないよう回復を挟み、種類・清潔さ・お宝・スリルのバランスで評価を伸ばします。清掃100%なら営業後15Gボーナス。作業かばんは3段階まで拡張できます。

## 保存と音

進行はブラウザのlocalStorageに自動保存します。夜の途中で閉じた場合は、その夜を開始する直前の準備状態から再開します。同じURL・ブラウザ内のみで有効です。リセット時は確認を表示します。効果音は初期OFFで、右上の♪からONにできます。

## 開発

- `dist/core.js`：ゲームルールと決定的シミュレーション
- `dist/app.js`：Canvas描画、入力、画面、セーブ、Web Audio効果音
- `dist/style.css`：レスポンシブUI
- `tests/core.test.cjs`：経済・連携・7日間進行などの回帰テスト
- `server.cjs`：依存パッケージなしのローカルサーバー

`npm test` でテストを実行します。

企画、文章、キャラクター、背景、UI、効果音はこのゲーム用のオリジナルです。外部サイトの引用・外部画像・外部音源・フォントCDN・ランタイム依存ライブラリは使っていません。ゲーム実行中に生成AIのAPIや通信は必要ありません。
