# 実装仕様と補足（1.0）

ユーザー指定を軸に、未指定部分の数値を以下のように決定。外部作品の文章・画像・音声素材は使用していません。

## 探索

- 初期HP100 / MP20 / 素早さ10 / 錬成1 / コイン30。剣6・瓶3＋ランダム3候補から選ぶ1属性4枚。
- 各階層に4段・各2〜4マス。隣接する段に必ず到達できる接続を生成。最初の段は戦闘、3段目は戦闘またはエリート（1〜2層では宝箱）、4段目に焚き火を最低1つ配置。各段で1マスを選ぶ。
- 地域は森林・廃都市・地下神殿から毎階層抽選。地域固有の敵・イベント・価格倍率を使用。
- 10の倍数の階層では階段がボス。通常モードは10階層のボス撃破で終了。エンドレスは続行。
- 戦闘勝利も階層突破も「カード2候補・バフ1候補」から1つ、またはスキップ。通常戦闘のコインは12＋階層×3。エリート＋20、ボス＋60。
- 階層突破でHP最大値10%・MP全回復。錬成回数は4層で2、7層で3、10層で4、13層で5。極意サービスも加算、上限5。

## 戦闘処理

ターン開始：MP回復（2ターン目〜）→火傷・毒→呪い・再生→死亡判定→手札5枚まで補充→敵予告→プレイヤーより速い敵→プレイヤー。終了を選ぶと未行動の遅い敵が行動し、持続時間を減らして次へ進みます。同速は主人公が先です。

高速敵の表示の✓は当該ターンに行動済み。途中の素早さ上昇でその行動を取り消しません。敵の予告は敵自身の行動回数から生成されます。麻痺では1回の行動を飛ばします。複数回攻撃は1行動として扱います。

使用・廃棄カードは山札の底へ。手札上限は5。抽出で上限時に引いたカードも山札の底へ。戦闘中の錬成は一時的で、次戦は元の恒久デッキをシャッフルします。精錬だけは恒久化。

初戦は属性＋剣を確実に配り、錬成前の使用・ターン終了・逃走を禁止。HP54・攻撃4の苔スライムで操作を習得します。

火傷・毒はスタック値だけダメージを与え、1ずつ減少。凍えは攻撃0.7倍。風・土・闘気は3ターン、2段階の加算。効果量が異なる風・土は強い2つを採用し、再適用で期間更新。土は固定軽減、HP/MP以外に防御力という恒久ステータスはありません。

## カードと錬成

全基本カードの値は `web/data.js`、45レシピの名前・攻撃力・MPも同ファイルで固定。

- 剣：10ダメージ/MP0、瓶：全体6/MP2。
- 属性は8〜12ダメージ/MP3（雷のみMP5）。火傷3・水回復5・麻痺1・毒4・凍え2・風速度3・土軽減4。
- 1段目は基本9種の重複を許す45組。2段目は少なくとも片方が1段目、合計4素材まで、効果値の合計を1.2倍。通常素材で3段目にはできません。
- 大：1.6倍。双：0.7倍を2回。重ねるたびに乗算。段数・素材数の制限に含まず、補助・レアにも付与可能。持続型は持続時間、カウンターは反撃係数、闘気は2段階上限の範囲で強化。確率100%の逃走・全解除・耐性解除など二値効果は成功率・解除量の上限を超えません。
- 精錬は1回20%、上限＋3。1段目は高い方の精錬を引き継ぎ、2段目は元カードの精錬を数値に折り込みます。
- 錬成時にMPと回数を消費。完成カードの使用MP0。大・双の追加も1回の錬成に数えます。分解は全元素材を戻し、累計の錬成MPの半分（切り捨て）を返します。手札に収まらない素材は山札の底へ。
- カウンター＋基本カードは1段目のみ。反撃0.9倍（元は0.75）、属性追加効果を反撃に付与。発動後最初の攻撃行動を無効化。その後も戦闘中反撃を継続。再使用で初撃無効化を再装填。
- サモンは5ターン、各攻撃の実ダメージ×0.25で追撃。ファランクスは2ターン無敵、1戦闘1回、恒久デッキ1枚。ショップでは常に320G。
- ダメージと効果値は整数に丸めます。弱点1.5倍、耐性0.55倍。混合属性で弱点と耐性の両方を含む場合は両倍率を順に適用。

## 遺跡の意思

内部Lv = 階層 + min(12,護符数)×0.18 + (最大HP−100)×0.012 + (最大MP−20)×0.035 + (錬成上限−1)×0.35 + 精錬合計×0.08 − 呪い数×0.14（最低1）。

通常敵HP = 基準HP×(1＋Lv×0.075)×1.5。エリートはさらに1.55倍。攻撃 = 基準×(1＋Lv×0.045)、エリートはさらに1.3倍。出現数は低層1〜2、高層2〜3。地域の6種から抽選。精錬や護符で強くなりすぎない程度の補正です。

ボスHP=(350＋周回×65)×(1＋max(0,Lv−10)×0.035)×1.3。攻撃18＋周回×4、素早さ8＋周回。HP半分未満で攻撃1.35倍・速度＋5・2回攻撃。弱点・耐性・適応なし。

直近3戦の攻撃カード使用比率を記録。混合属性は属性数で分割、無属性も分母に含めます。60%以上の属性を次戦の耐性＋反撃に設定、40%未満で解除。ボスは例外。適応性格の敵は戦闘中にも最多使用属性に耐性を変更。観測ログで内部Lvと選択を確認できます。

## 施設とデータ

ショップ：通常棚3〜5枚＋ファランクス1枚、護符3候補。森林−10%、都市＋10%、神殿標準。回復25G（HP50%）、魔力18G、精錬35G、除去30G、解呪45G（1個）、極意120Gに地域補正。カード除去はデッキ最低5枚。

休憩：HP30%・MP全回復・精錬1枚から1つ。宝箱：40%コイン、40%カード、20%護符。護符の30%が呪い付き（全体6%）。開封前の調査で判別可能。

イベント：共通3、地域各3、レア2。レアイベント確率8%。主人公はしゃべらず、選択肢は行動のみ。バフ27・デバフ8は `data.js` に説明付きで列挙。

## 保存・実装上の範囲

ローカル保存は操作後と10秒ごと。戦闘中の手札・敵・乱数状態まで保存。ネットランキング・アカウント・課金はありません。Windows版はElectron runtimeを同梱したフォルダ形式のEXEです。

20〜30分は設計目標。手動の長時間・複数構築のバランス検証は今後も必要です。ルール回帰テストとブラウザでの代表操作を実施し、検証内容は `TESTING.md` に記録しています。
