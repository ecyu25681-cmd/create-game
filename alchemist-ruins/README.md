# 錬金術師と変幻の遺跡

オリジナルのデッキ構築ローグライク。カードを重ねて錬成し、姿を変える遺跡を探索するゲームです。ドット絵はCanvas、5曲のBGMと効果音はWeb Audioで生成します。画像・音声ファイル、外部フォント、CDN、通信機能はありません。前作『勇者のあとしまつ』とは別作品です。

## 遊ぶ

Windows版：ZIPをフォルダごと展開して **AlchemyRuins.exe** をダブルクリックしてください。EXEの隣のDLL・resources・localesなども必要です。EXE単体の移動では起動できません。インストール不要のWindows x64用です。

ブラウザ版：`web/index.html` をEdgeまたはChromeで開いてください。ローカルファイルに制限のある環境では、Node.jsで `npm start` を実行し `http://127.0.0.1:4320` を開きます。Windows版はNode.jsの別途インストール不要です。

進行は自動保存。タイトルの「探索をつづける」で再開できます。Windows版と各ブラウザ版では保存場所が別です。新しい探索を始めると現在の探索を置き換えますが、錬成録・制覇回数・エンドレス最高階層は残ります。

## 操作

- 攻撃カードを敵へドラッグ。自分用カードは「自分に使う」枠へ。
- カードを別のカードへ重ねると錬成。光る相手に合わせると完成名とMPを表示します。
- 背景で離すと何も消費せず手札に戻ります。
- クリックでカードを選択し、敵・自分枠・別のカードをクリックする操作も使えます。
- 「すてる」でカードを選ぶか、ごみ箱へドラッグ。1ターン1枚まで。
- `E`：ターン終了。`Esc`：選択解除・ダイアログを閉じる。
- 設定でBGMと効果音を個別に切り替え。最初の操作から音が始まります。

## 内容

ダンジョン制覇（10階層目のボスでクリア）、エンドレス（10階層ごとにボス）、7属性、基本45レシピ、2段階錬成、27バフ、8デバフ、3地域、18種の通常敵、エリート、14イベント、ショップ、休憩、宝箱、錬成録、適応AIと観測ログ。

細部の数値・処理順・追加解釈は `SPEC.md` に記載しています。目標プレイ時間は20〜30分ですが、操作速度や構築によって変わり、実プレイでの所要時間調整は継続課題です。

## 開発・テスト

依存ライブラリ不要。`npm test` でルールの回帰テストを実行できます。`npm start` はループバック限定の静的サーバーです。

`npm run build:win` で、公式Electron 44.9.1 Windows x64を取得し、SHA-256を検証して `release/AlchemyRuins-Windows` に配置します。既存出力は上書きしません。既存の公式ZIPを使う場合：

```powershell
powershell -NoProfile -File scripts/build-windows.ps1 -RuntimeZip C:\path\electron-v44.9.1-win32-x64.zip -Destination C:\path\AlchemyRuins-Windows
```

Electron配布元： https://github.com/electron/electron/releases/tag/v44.9.1

検証したSHA-256： `41bd7900bd42d0f49110a81617876137041fbbf473466920248ddb076349ef91`

Electron本体のLICENSE・LICENSES.chromium.htmlをWindows版に同梱します。ゲームのソースには利用許諾を別途設定していません。配布EXEに独自のコード署名は付けていません。
